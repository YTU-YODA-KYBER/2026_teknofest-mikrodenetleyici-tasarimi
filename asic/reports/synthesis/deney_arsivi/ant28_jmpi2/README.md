# `ant28_jmpi2` deney arşivi

`ant28` adım 43 durumundan, yalnız `GRT_ANTENNA_REPAIR_ITERS` 1'den 2'ye
çıkarılarak yürütülen saf-jumper deneyinin küçük kanıt dosyalarıdır.

İkinci tur 655 ihlali tekrar görmüş, fakat 0 jumper / 0 net eklemiştir.
RepairAntennas çıkış ODB ve DEF dosyaları `ant28` iter=1 çıktılarıyla bit bit
aynı olduğundan DRT kontrollü durdurulmuştur; post-DRT sonucu ölçülmemiştir.
