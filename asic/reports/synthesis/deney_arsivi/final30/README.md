# `final30` arşivi

30 MHz hedefli, signoff zamanlamasında başarısız olmuş tam koşumun silinmeden
önce saklanan karar verici çıktılarıdır. Kaynak koşum dizini:
`/usr/asic_flow/run/final30`.

- `final_metrics.json`: koşumun `final/metrics.json` dosyası
- `summary.rpt`: `57-openroad-stapostpnr/summary.rpt`
- `resolved.json`: fiilen çözülmüş LibreLane yapılandırması

Koşumun sayısal değerlendirmesi `reports/synthesis/strateji_denemeleri.md`
içinde kayıtlıdır.
